# PizzUM & BurgUM — Sistema Web de Gestión de Pedidos
Proyecto desarrollado como parte del obligatorio 2025 de la asignatura Proyecto TIC. Consiste en la implementación de una aplicación web para el restaurante ficticio PizzUM & BurgUM, orientada a optimizar la gestión de pedidos y mejorar la experiencia tanto del personal como de los clientes. La aplicación permite registro e inicio de sesión de usuarios, acceso a menús diferenciados para cliente y personal, realización y visualización de pedidos, actualización de datos de cuenta y gestión de ingredientes (consulta, alta y baja).
